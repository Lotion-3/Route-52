FOR ALAN LAI AND NOVAK G.

Step 1

Go to cmd, navigate to the root directory (`basketBuddy`) and execute:

`backend\.venv\Scripts\activate`

after running that command, you will see "(.venv)" on the left hand side of each line in cmd.

THEN

`cd backend`
`python server.py` (starts the backend server)

THEN MAKE A NEW TERMINAL
 make sure you are in the frontend repo

 then "npm start"

 Wait til everything loads and then open it

 To check if the backend is communicating with the frontend: 
 - *right click* and then click inspect
- go to console and monitor it

also monitor the backend server's terminal to make sure everything is running right
